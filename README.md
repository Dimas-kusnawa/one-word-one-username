A program that writes exactly one word to `/output/entry.txt`: the entrant's own make.fun username, "dimas-kusnawa". The bounty asks for one word and nothing else, and the judge's first criterion is that the entry is a real make.fun username — a genuine handle beats any invented word, so the entry is the real handle, no explanation, no links, no pitch.

## Run it

```sh
python3 main.py
```
